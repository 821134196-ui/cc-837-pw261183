# 灰度发布演练台（canary-lab）

用模拟资源演示一次**同时改动网关路由、实例版本和配置**的灰度发布，重点是：
**控制面进程在灰度中途被停掉后，恢复能接着做完，且绝不重复放大流量。**

仅依赖 Python 3.11 标准库，无第三方依赖。

## 快速开始

```bash
# 1. 启动数据面 + Web 控制台（默认端口 18080）
python3 -I dataplane.py

# 2. 浏览器打开
#    http://127.0.0.1:18080

# 3. 无浏览器的端到端自测（另开终端，会自行拉起临时数据面）
python3 -I selftest.py 18099
```

页面上两种用法：

- **一键演练**：场景 A（断控恢复后补齐全量）/ 场景 B（恢复后注入故障并撤回），
  脚本自动在 50% 决策点 SIGKILL 控制器再重启。
- **手动操作**：启动控制器 → 创建发布单 → 在 50% 决策点随时
  「SIGKILL 模拟宕机」→ 重启 → 点「补齐」或「撤回」；也可对实例注入故障。

## 模拟的三类资源

| 资源 | 模拟内容 | 关键约束 |
| --- | --- | --- |
| 网关路由 | v1/v2 权重、生效配置版本 | 权重只接受**绝对值** `setWeight(w)`，服务端按 100−w 设 v1；相同值重复调用幂等跳过并写审计 |
| 实例池 | 版本、挂载配置、健康/运行状态 | 先建实例、挂配置，确认健康后才接流量 |
| 配置中心 | cfg-v1 / cfg-v2 两份配置 | 网关与实例的配置切换都留痕 |

## 发布阶段机

```
ENSURE_V2 → ATTACH_CONFIG → SHIFT(0→10→25→50) → GATE(50% 人工决策点)
                                   ├─ 补齐 → SHIFT(75→100) → 网关切 cfg-v2 → FORWARD_CLEANUP(终止 v1)
                                   └─ 撤回 → ROLLBACK_SHIFT(50→25→10→0) → CLEANUP(终止 canary、恢复 cfg-v1)
```

每 500ms 一个调谐 tick，每个 tick 最多执行一个变更动作，每个新权重位有健康观察期。

## 断控恢复是怎么做到「不重复放大」的

1. **全部状态持久化**：控制器每个状态/事件变化都原子写盘
   （`run/controller/controller_state.json`、`controller_events.jsonl`），
   人工决策也落盘成 `decision.json`，SIGKILL 不丢状态。
2. **重启先核对、后动作**：带旧状态重启时，第一个动作是 `RECONCILE_VERIFY`——
   读取数据面**实际**权重/实例/配置，与期望逐项比对，并**以实际权重为唯一基准**
   重对齐阶梯索引；核对完成前不碰任何流量。
3. **权重只有绝对值，没有增量**：控制器从不发“再加 10%”，只发“设为 25%”。
   即使 kill 恰好发生在「数据面已改、控制器未记」的窗口，恢复后重发的也是同一个绝对值，
   数据面幂等跳过，机制上不存在二次放大。
4. **决策前冻结**：恢复核对后、人工补齐/撤回决策落盘前，控制器不允许任何权重变更。
5. **数据面与控制面解耦**：控制器被 kill 期间，数据面资源保持实际状态不漂移。

## 页面如何保留「每次动作的依据和实际状态」

- **控制器事件流**：每条事件包含 `basis`（动作依据）、`observed`（当时数据面实际状态快照）、
  `action`（实际执行的动作）、阶段/步进/生命周期 epoch/时间戳。
- **数据面命令审计**：所有资源操作带序号、参数、说明；被幂等跳过的重复命令单独标注。
- **场景演练日志**：断控时刻的数据面实际值、核对结论、决策理由逐步留痕。
- **模拟流量面板**：v1/v2 RPS 与 v2 错误 RPS（v2 全不健康时错误量随权重增长，可直观看到故障影响）。

## 文件说明

```
canary-lab/
├── controller.py    # 控制面：独立进程，调谐循环 + 持久化 + 恢复核对 + 阶段机
├── dataplane.py     # 数据面：模拟资源/HTTP API/控制器进程监管/场景演练/流量模拟/静态页服务
├── selftest.py      # 端到端自测（两条场景 + 断控幂等 + 偏离崩溃窗口断言）
├── web/index.html   # 控制台单页（原生 JS，无构建）
└── run/             # 运行时状态（已 gitignore）
    ├── dataplane_state.json
    └── controller/  # state.json / events.jsonl / decision.json / stdout.log
```

## 主要 HTTP API

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| POST | `/api/control/start` `/stop` `/kill` | 启动 / 优雅停止 / SIGKILL 控制器进程 |
| POST | `/api/reset` | 重置全部模拟资源与控制器状态 |
| POST | `/api/releases` | 创建灰度发布单（路由+版本+配置联动） |
| POST | `/api/decision` | 人工决策落盘（`continue` 补齐 / `abort` 撤回） |
| POST | `/api/gateway/weight` | 绝对值设置 v2 权重（重复值幂等跳过） |
| POST | `/api/instances`、`.../config`、`.../terminate` | 实例创建/挂配置/终止 |
| POST | `/api/fault/instances/{id}` | 故障注入/恢复 |
| POST | `/api/scenario/run` | 运行 `success` / `rollback` 演练 |
| GET | `/api/state` | 全量状态（页面轮询） |
